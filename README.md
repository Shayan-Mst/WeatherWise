# 🌤️ WeatherWise

**WeatherWise** is a full-stack weather application that provides real-time weather data and allows users to save city weather information using a Node.js backend.

Built with:
- A **responsive frontend** using HTML, Tailwind CSS, and JavaScript.
- A **Node.js + Express backend** to save and retrieve city weather info.


---

## 🚀 Tech Stack

### 🖥️ Frontend:
- HTML5
- Tailwind CSS
- JavaScript (ES6)
- AccuWeather API

### 🔧 Backend:
- Node.js
- Express.js
- (Optional: MongoDB or file storage if used)

---

## ✨ Features

- 🌍 Search current weather by city
- 📌 Save searched cities and retrieve their data
- 🧠 Stores weather info using a Node.js server
- 💻 Fully responsive design
- ⚡ Fast API integration with Accuweather

## 📦 Getting Started

### Clone the repository

```bash
git clone https://github.com/Shayan-Mst/WeatherWise.git
cd WeatherWise

1. Install server dependencies

npm install

2. Start the Node.js server

node server.js

    The backend should run on http://localhost:3000

3. Open the frontend

Simply open index.html in the browser or serve it using Live Server in VS Code.
🔑 API Key Setup

    Get your API key from ACcuweather

   

    Replace YOUR_API_KEY_HERE with your actual key in js frontend files:

const apiKey = "YOUR_API_KEY_HERE";
